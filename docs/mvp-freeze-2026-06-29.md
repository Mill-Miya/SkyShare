## 現在の目的

Soravaは天文シミュレーターではなく、観望会で参加者が同じ対象天体や同じ空の方向を短時間で見つけるための軽量なWebアプリです。

最優先は、スマホブラウザからすぐ開けること、Hostが選んだ案内をGuestに共有できること、低通信量で30分程度の部内テストに耐えることです。

## Host / Guestの仕組み

HostはSession画面からセッションを作成し、sessionIdと参加URLを発行します。GuestはQR、参加URL、または参加コードから参加します。

サーバーは天体計算を行わず、セッション管理と共有状態の中継だけを行います。共有するのは基本的にtargetId、共有OFF、またはSky画面中央方向のpointerです。

共有しないもの:

- HostのGPS
- GuestのGPS
- Hostの時刻
- Guestの時刻
- Hostの物理的な端末姿勢
- Guestの物理的な端末姿勢

## PASS機能

公開版ではPASS `0629` を入力してからアプリを利用します。

- 通常URLでもPASS入力画面を表示
- `/join/{sessionId}` でもPASS入力画面を表示
- 正しいPASSならGuest参加または通常アプリ表示へ進む
- 誤入力時はsessionStorageにロック状態を保存
- 誤入力後は同一タブで再試行不可
- 外部URLへリダイレクトしない
- WebSocket接続やjoinSessionは開始しない

これは本格認証ではなく、部内テスト用の簡易ゲートです。

## 太陽高度による明るさ判定

現在地と現在時刻から太陽高度を計算し、空の明るさ目安を表示します。

分類:

- 昼: 太陽高度 0度以上
- 市民薄明: 0度未満、-6度以上
- 航海薄明: -6度未満、-12度以上
- 天文薄明: -12度未満、-18度以上
- 夜: -18度未満

Targetsの上部に `天文薄明 / 太陽 -15°` のように表示します。

おすすめカテゴリでは、明るい空の時間帯にMessier天体や二重星が出にくくなるよう調整しています。

注意:

- 実際の空の明るさを測る機能ではありません
- 雲、月明かり、街明かり、霧、周辺照明は考慮しません
- 太陽高度から推定した観望目安です

## センサー追従

Sky画面の手動 / 追従ボタンでDeviceOrientationを使った追従に切り替えられます。

- iOSでは必要時にユーザー操作で権限要求
- Androidでは権限APIがない場合そのままイベントを待機
- Settingsに上下反転トグルあり
- 管理者画面でSensor Probeを確認可能
- スワイプ操作を始めると手動モードへ戻る

センサー値は端末差が大きいため、部内テストでは手動操作でも成立することを前提にしています。

## 手動モード

手動モードでは、Skyをスワイプ・ピンチ操作で動かします。追従が不安定な端末でも、Host共有・Guest誘導・方向共有は手動操作で利用できます。

## 既知の注意点

- GitHub Pagesは古いAndroid端末で証明書エラーになる場合があります
- Render Freeはスリープするため、部内テスト前に `/health` を開いて起こす必要があります
- DeviceOrientationは端末・OS・ブラウザにより挙動が異なります
- PASSはフロントエンドに埋め込まれる簡易ゲートで、本格認証ではありません
- 星空背景や山は観測補助の演出で、実地形や実際のオーロラではありません
- 太陽高度判定は天候や月明かりを考慮しません
